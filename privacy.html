Privacy Policy

Last updated: October 6, 2026

This Privacy Policy describes how ACP Control Software processes information related to its outbound email functionality.

Google API Usage

ACP Control Software uses the Google Gmail API only to send outbound email messages from a dedicated application-controlled Gmail account.

End users are not required to connect, authorize, or provide access to their own Gmail or Google accounts.

ACP Control Software does not use the Gmail API to access an end user's mailbox and does not read, modify, delete, or otherwise inspect messages in an end user's Gmail account.

Information Processed for Email Delivery

When outbound email is sent, ACP Control Software may process:

  • Destination email addresses
  • CC addresses, if configured
  • Email subject text
  • Email message body content
  • Application-generated or user-selected file attachments

This information is used only for constructing and sending the requested outbound email message.

Google OAuth Credentials

Google OAuth credentials used by ACP Control Software are associated only with the dedicated Gmail account used by the application for outbound email delivery.

These credentials are not associated with an end user's Gmail account.

OAuth access tokens may be held temporarily in memory while Google API requests are performed. Long-lived authorization credentials may be stored locally on systems where ACP Control Software is installed.

Use of Information

Information processed by ACP Control Software for email delivery is used solely to send application-related notifications, reports, status messages, and attachments.

Information is not used for advertising, behavioral profiling, marketing, or sale to third parties.

Storage

ACP Control Software does not maintain a separate cloud database of outbound email content through this Gmail API integration.

Sharing of Information

Information required to send email is transmitted to Google only as necessary to deliver outbound messages through the Gmail API.

ACP Control Software does not sell or rent email addresses, message contents, attachments, or Google authorization information.

Data Retention

Retention of locally stored application data depends on the configuration and operation of the installed ACP Control Software system.

End-User Google Accounts

ACP Control Software does not require end users to provide Google account credentials or authorize access to their personal or organizational Gmail accounts.
