Privacy Policy

Last updated: October 6, 2026

This Privacy Policy describes how ACP Control Software uses information obtained through Google APIs.

Google API Access

ACP Control Software may request authorization to use the Gmail API for the purpose of sending outbound email messages.

The application requests only the permissions necessary to send email. It does not use the Gmail API to read, modify, or delete messages from the user's mailbox.

Information Used

When sending email, the application may process information supplied by the user or generated by the application, including:

  • Email recipient addresses
  • CC recipient addresses
  • Email subject and message body
  • User-selected or application-generated file attachments
  • OAuth access and refresh tokens required to authorize Gmail API requests

Use of Information

Information accessed through Google APIs is used solely to send outbound email messages requested or configured by the user.

Google user data is not used for advertising, profiling, or marketing.

Storage and Security

OAuth credentials and tokens may be stored locally on systems where ACP Control Software is installed. Reasonable measures are used to protect stored credentials and tokens from unauthorized access.

Access tokens may be held temporarily in memory while Gmail API requests are performed.

Sharing of Information

Google user data is not sold, rented, or shared with third parties except as necessary to communicate with Google services for the purpose of sending email, or where required by law.

Data Retention

ACP Control Software does not maintain a separate cloud database of Gmail message content. Locally stored OAuth credentials or tokens may remain on an installed system until removed, replaced, revoked, or the application is uninstalled or reconfigured.

Revoking Access

Users may revoke ACP Control Software's access to their Google account through their Google Account security settings.
