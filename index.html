ACP Control Software

ACP Control Software is a desktop application used for control, monitoring, data acquisition, and automated reporting.

The application can use the Google Gmail API to send outbound email notifications, status messages, reports, and user-selected file attachments.

Gmail access is limited to sending email. The application does not use the Gmail API to read, modify, or delete messages from the user's mailbox.
