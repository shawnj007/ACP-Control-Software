ACP Control Software

ACP Control Software is a desktop application used for control, monitoring, data acquisition, and automated reporting.

The application can send outbound email notifications, reports, status messages, and attachments using the Google Gmail API.

Email is sent from a dedicated application-controlled Gmail account. End users are not required to connect, authorize, or provide access to their own Gmail accounts.

The application does not access an end user's Gmail mailbox and does not read, modify, or delete messages from an end user's Google account.

Email Functionality

ACP Control Software may send email containing information generated by the application or provided by the operator, including:

  • Destination email addresses
  • CC addresses, if configured
  • Email subject and message body
  • Application-generated or user-selected file attachments

Google OAuth credentials are associated only with the dedicated sender account used by ACP Control Software.
